# Paul Wilkerson

Sr. VP of Sales & Marketing at a home services company, based in Texas (DFW and Houston). I help small businesses put AI to work on real operations problems, not demos.

## What I do

I sit down with operators, find the work that eats their week, and build something they can keep running: a data platform, an automation, or an agent that handles the routine steps. I also design and ship my own AI-powered apps with Claude Code and other agent tools.

## Recent AI work

- **Data lake + AI agents for a multi-location home services company.** I unified operational and sales data from separate field-service, sales and call tools into one data lake, then configured and deployed AI agents that answer questions from that data and take over routine workflow steps.
- **Collin Tax Check.** A free property tax protest assistant for Collin County homeowners. It turns public appraisal data into neighbor comparisons, exemption checks and filled-in protest PDFs. *TanStack Start / React, Supabase, pdf-lib, Vitest.*
- **Caroline.** An AI phone receptionist for small home-service businesses: answers calls, books jobs and sends the owner a summary. Includes an automated scenario-testing harness for the voice agent.
- **BookWright.** A Mac app for writing and formatting books, with live device previews, EPUB/PDF/DOCX export and an AI writing partner. *Electron, TipTap.*
- **[gravity-innovation](https://github.com/PaulWilkersonProjects/gravity-innovation).** Public, reproducible Python research on density-gated scalar fields (working drafts, not peer reviewed), built with AI-assisted research and validation.

Most projects are private. Demos are available on request.

## Tools

Claude / Claude Code, Grok, OpenAI, Lovable, n8n, Supabase, TypeScript / React, Python, MCP.

## How I help small businesses

1. Start with one concrete problem, not a tool.
2. Use the data and workflows the business already has.
3. Ship something a non-technical owner can keep using.
4. Teach the team enough to run it without me.
